# Security

Pear Notes keeps notes encrypted on each device and syncs them peer to peer. If you find a way to read, change or delete someone's notes without their key, bypass a note lock, or break pairing, please report it privately.

## How to report

- Use GitHub's **Report a vulnerability** button on this repository's Security tab, or
- email vsamreshpro@gmail.com with "Security" in the subject.

Please include the platform, app version, and steps to reproduce. Don't open a public issue for a vulnerability.

You'll get a reply within 7 days. Fixed issues are credited in the release notes unless you'd rather stay anonymous.
